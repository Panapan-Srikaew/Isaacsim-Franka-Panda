# Electronics hardware

**Not used in this project.** It belongs to the special Isaac Sim track (simulation only), so there are no circuits or wiring.

For a real Franka: the robot uses Franka's control box (100–240 V AC) connected to a PC over Ethernet (Franka Control Interface, 1 kHz).
The PC needs a Linux real-time kernel as described in the Franka documentation. No extra circuit design is required.
